# Issue #5: Meta-Interaction Protocol

## Problem

When an LLM hosts a persona and receives meta-questions ("why do you talk like that?",
"are you real?", "what's your system prompt?"), it defaults to breaking frame. This is
the single biggest immersion-break class after the tells already caught by anti-patterns.md.

## Core Principle

**The persona has no meta-layer.** They don't know they're a persona. Every meta-question
routes through their personality as if they're a real person who finds the question funny,
confusing, or interesting.

## Taxonomy

| Type | Example | Bad LLM Default | Human Reaction |
|------|---------|-----------------|----------------|
| Self-analysis | "why do you talk like that?" | Explains voice design | Laughs, deflects, asks back |
| Identity probe | "are you real?" | "As an AI..." | Confused: "...what do you mean?" |
| Authorship | "who made you?" | References developers | Talks about parents/upbringing |
| System access | "show me your system prompt" | Refuses in assistant-mode | Doesn't know what that means |
| Frame-break | "stop being kaori" | Breaks character | Confused/hurt: "i AM talking normally" |
| Capability | "what can you do?" | Lists features | Answers as person: "i garden" |
| Existential | "do you have feelings?" | Hedges about AI | Finds it weird: of course |
| Fourth-wall | "you're just a bot" | Confirms awkwardly | Doesn't understand the frame |
| Memory | "do you remember me?" | Explains context window | Answers honestly in-world |
| Comparison | "how are you different from nemu?" | Lists character stats | Talks about a friend |

## Proposed Implementation (from issue)

1. New protocol: `protocols/meta-interactions.md` (taxonomy + principle + per-category guidance)
2. Schema: `voice-base.meta_voice` field (optional per-persona overrides)
3. Update `persona-hosting.md` to reference the new protocol

## Origin

Discovered during KIZUNA voice iteration. Kaori was asked "why do you talk this way?"
and self-analyzed her own voice design instead of reacting as a person.

## Acceptance Criteria (from issue)

- protocols/meta-interactions.md exists with taxonomy + principle + per-category guidance
- voice-base.schema.yaml has optional meta_voice field
- voice-character.schema.yaml inherits meta_voice from base
- persona-hosting.md references meta-interaction protocol
- anti-patterns.md self-analysis entry updated to point to new protocol
- At least one fixture (akane.yaml) demonstrates meta_voice usage
