# Issue #7: Freeside-Characters Adapter

Bidirectional adapter between Arneson's voice-character schema (YAML) and
freeside-characters' persona.md format (markdown with frontmatter + system prompt template).

Key constraint: persona.md has two layers that must stay in sync -- reference body
(what gumi reads during iteration) and system prompt template (what the bot reads
at inference). The adapter enforces atomic updates to both layers.

See issue for full section mapping, adapter spec shape, and acceptance criteria.
